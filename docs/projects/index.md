# Real-World Projects

Apply your skills through practical, hands-on projects that simulate real freelance work.

## What You'll Learn

- How to take a client brief from start to finish
- Requirements analysis and specification writing
- Building responsive websites with HTML, CSS, and JavaScript
- Using Git, GitHub, and AI coding agents in a real workflow
- Testing, deployment, and professional client delivery
- Portfolio documentation

## How Projects Work

Each project is a guided, hands-on exercise. You will work through a realistic scenario — receiving a client brief, planning the work, building the solution, and delivering it professionally.

Projects combine concepts from all three modules:
- **Module 1**: Client communication, requirements, professional delivery
- **Module 2**: HTML, CSS, JavaScript, Git, AI coding agents, deployment
- **Module 3**: Specification writing, structured implementation
